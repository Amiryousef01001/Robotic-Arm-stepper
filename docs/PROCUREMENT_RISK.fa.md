# ارزیابی ریسک تهیه قطعات Moveo در ایران

## نتیجه کوتاه

ساخت پروژه در ایران **شدنی است**، اما تضمین نمی‌کنیم همه قطعات با همان مدل، همان ابعاد و همان موجودی BOM اصلی پیدا شوند. ریسک اصلی کمبود موتور نیست؛ ریسک اصلی قطعاتی است که باید با ابعاد دقیق Moveo جور باشند، مخصوصاً پولی‌های T5، تسمه‌های هم‌عرض، شفت/بوش‌های خاص و گیربکس‌های چاپی.

برای همین، قبل از مصرف حدود ۲ کیلو فیلامنت، باید یک مرحله خرید/اندازه‌گیری انجام شود.

## 1) قطعات با ریسک کم برای تهیه داخل ایران

| قطعه | وضعیت معمول | توضیح |
|---|---|---|
| Arduino Mega 2560 clone | معمولاً قابل تهیه | نسخه اصل لازم نیست؛ برای نمونه اولیه clone کافی است |
| RAMPS 1.4 | معمولاً پیدا می‌شود، ولی موجودی فروشگاه‌ها تغییر می‌کند | قبل از خرید وضعیت واقعی را چک می‌کنیم |
| A4988/DRV8825 | قابل تهیه | A4988 برای تست کم‌هزینه مناسب است؛ جریان موتور باید با دیتاشیت هماهنگ شود |
| NEMA17 | قابل تهیه | مدل‌های ۱٫۸ درجه، شفت ۵ میلی‌متر و حدود ۳ kg·cm رایج‌اند |
| MG995/MG996R | قابل تهیه | تغذیه جداگانه ۵ تا ۶ ولت لازم است |
| پیچ و مهره M3/M4/M5 | معمولاً قابل تهیه | بهتر است سایزهای پرمصرف را به‌صورت کیت بخریم |
| بلبرینگ‌های رایج | معمولاً قابل تهیه | مثل 608، 623، 624/625؛ سایز دقیق هر BOM باید کنترل شود |
| شفت و میل صاف ۸ میلی‌متر | قابل تهیه/قابل برش | طول‌ها را می‌توان از شاخه بلند برش داد |
| فیلامنت PLA/PETG/ABS | قابل تهیه | انتخاب جنس به محفظه و شرایط چاپ بستگی دارد |

فروشگاه‌های ایرانی برای A4988، قطعات پرینتر سه‌بعدی، تسمه/پولی T5 و NEMA17 لیست محصول دارند، اما این به معنی موجودبودن همه مدل‌های دقیق در زمان خرید نیست: [A4988](https://partineh.com/product/%D8%AF%D8%B1%D8%A7%DB%8C%D9%88%D8%B1-%D8%A7%D8%B3%D8%AA%D9%BE%D8%B1-%D9%85%D9%88%D8%AA%D9%88%D8%B1-a4988)، [T5](https://partineh.com/category/T-series-timing-belt-and-pulley)، [RAMPS](https://ickala.com/arduino-shield/25177-lcd-keypad-shield.html)، [NEMA17](https://torob.com/p/bc618976-6a90-421d-9525-d14a2f846da5/%D8%A7%D8%B3%D8%AA%D9%BE%D8%B1-%D9%85%D9%88%D8%AA%D9%88%D8%B1-%D9%86%D9%85%D8%A7-17-nema-%D9%85%D8%AF%D9%84-17hd48002/).

## 2) قطعات با ریسک متوسط یا زیاد

### پولی‌های T5 با تعداد دندانه خاص

اعداد فعلی ما:

```text
پولی موتور: 13 دندانه
پولی شانه: 77 دندانه
پولی آرنج: 61 دندانه
پولی مچ: 45 دندانه
```

فروشگاه‌های عمومی معمولاً مدل‌های استانداردی مثل ۱۲، ۱۶، ۲۰، ۲۲، ۳۶، ۴۸ یا ۶۰ دندانه را لیست می‌کنند؛ ۱۳، ۴۵، ۶۱ و ۷۷ ممکن است آماده پیدا نشوند. راه‌حل‌ها:

1. پیدا کردن پولی آلومینیومی با تعداد دندانه نزدیک و اصلاح CAD؛
2. سفارش ساخت/تراش؛
3. چاپ پولی برای تست بدون بار؛
4. نگه‌داشتن تعداد دندانه فعلی و سفارش از خارج.

برای شانه، پولی چاپی را برای تست کوتاه‌مدت قبول می‌کنیم، ولی برای بار واقعی بهتر است پولی فلزی یا شفت‌دار با بوش فلزی استفاده شود.

### اختلاف ۱۳ و ۱۴ دندانه را حتماً بررسی کنیم

در بعضی نسخه‌های BOM منتشرشده Moveo، پولی T5 اصلی به‌صورت ۱۴ دندانه با bore هشت میلی‌متر ثبت شده است؛ یک BOM mirror نیز همین مقدار را نشان می‌دهد: [BOM mirror](https://idoc.pub/documents/bcn3d-moveo-bom-for-proto-plant-d47757zwj242). این منبع جایگزین CAD رسمی نیست، اما نشان می‌دهد شمارش ۱۳ دندانه باید در SolidWorks دوباره کنترل شود.

اگر عدد واقعی ۱۴ باشد، نسبت‌ها عوض می‌شوند:

```text
77/14 = 5.50
61/14 = 4.36
45/14 = 3.21
```

قبل از سفارش پولی، از نمای دقیق CAD یا با شمارش دندانه در مدل تأیید می‌کنیم؛ یک دندانه اختلاف روی نسبت کل و steps اثر دارد.

### موتورهای اصلی BOM

Moveo اصلی از موتورهای مختلف، از جمله NEMA23 و NEMA14، استفاده می‌کند و تجربه پروژه‌های بازسازی‌شده نشان می‌دهد بعضی مدل‌های دقیق BOM دیگر به‌راحتی پیدا نمی‌شوند. این برای ما مشکل بزرگی نیست، چون تصمیم گرفته‌ایم موتورهای موجود NEMA17 را با آداپتور و گیربکس استفاده کنیم.

### شفت‌ها و بوش‌های خاص

طول بعضی شفت‌ها در BOM و CAD یکسان گزارش نشده است. بهتر است یک شاخه شفت بلند بخریم و قطعات را بعد از اندازه‌گیری CAD برش دهیم، نه اینکه طول‌ها را کورکورانه از BOM سفارش دهیم.

## 3) آیا ۲ کیلو فیلامنت ریسک بزرگی است؟

دو کیلو برای یک نسخه Moveo سبک می‌تواند کافی باشد، اما عدد نهایی به support، infill، تعداد دیواره‌ها، قطعات آزمایشی و نسخه اصلاح‌شده شانه بستگی دارد. اگر slicer عدد ۲ کیلو نشان می‌دهد، برای خراب‌شدن چند قطعه بهتر است حدود ۱۵ تا ۲۵ درصد ذخیره داشته باشیم.

پیشنهاد اقتصادی:

1. اول با PLA/PLA+ موجود مدرسه، فقط adapter شانه و یک قطعه تستی چاپ شود؛
2. نسبت تسمه و جاگیری گیربکس تأیید شود؛
3. بعد برای قطعات نهایی PETG یا ABS خریداری شود؛
4. کل قطعات را یک‌باره چاپ نکنیم؛ هر مرحله بعد از تأیید مرحله قبل انجام شود.

اگر امکان تهیه فقط ۲ کیلو وجود دارد، آن را به این ترتیب مصرف کنیم:

```text
نمونه آداپتور و test rig → قطعات پایه و شانه → لینک‌ها → مچ و گریپر
```

چاپ ABS بدون محفظه و تهویه در مدرسه می‌تواند هم باعث شکست چاپ و هم مشکل ایمنی شود؛ اگر محفظه مناسب نداریم، PETG انتخاب کم‌ریسک‌تری برای نسخه اول است.

## 4) شرط‌های «اجازه چاپ کامل»

تا وقتی این موارد تأیید نشده، چاپ کامل را شروع نمی‌کنیم:

- [ ] تعداد دندانه پولی‌ها از CAD نهایی تأیید شده است؛
- [ ] گام و عرض تسمه T5 مشخص است؛
- [ ] یک پولی ۱۳/۱۴ دندانه واقعی برای شفت گیربکس پیدا شده یا CAD اصلاح شده است؛
- [ ] طول، قطر خروجی و محل پیچ گیربکس‌های ۳۸:۱ و ۵۰:۱ اندازه‌گیری شده است؛
- [ ] موتور NEMA17 از نظر سوراخ نصب، طول بدنه، قطر شفت و جریان با adapter سازگار است؛
- [ ] شانه با یک نمونه چاپی بدون payload مونتاژ و آزادشدن تسمه بررسی شده است؛
- [ ] RAMPS، درایورها، منبع تغذیه و MG995 تهیه یا در مدرسه موجود هستند؛
- [ ] برای ABS محفظه/تهویه یا برای PETG تنظیم چاپ آماده است.

## تصمیم پیشنهادی

به‌نظر من ریسک پروژه قابل قبول است، به شرطی که **ریسک را به خرید ۲ کیلو فیلامنت منتقل نکنیم**. ابتدا باید یک BOM بومی و یک test rig کوچک بسازیم. اگر پولی‌های خاص آماده پیدا نشدند، CAD را بر اساس پولی‌های قابل تهیه اصلاح می‌کنیم و نسبت‌ها را دوباره در firmware حساب می‌کنیم.
