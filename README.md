# بازوی رباتیک استپر / Robotic Arm Stepper

این مخزن برای طراحی و ساخت یک بازوی رباتیک چاپ سه‌بعدی ۵ یا ۶ محوره است؛ با موتورهای استپر، گیربکس‌های سیاره‌ای چاپی ۳۸:۱ و ۵۰:۱، سروو MG995 برای گریپر و کنترلر Arduino Mega 2560 + RAMPS 1.4.

> وضعیت فعلی: **فاز صفر؛ تعیین نیازمندی و معماری نرم‌افزار**. هنوز هیچ قطعه‌ای برای ابعاد یا موتور مشخص، قطعی فرض نشده است.

## تصمیم فعلی پروژه

1. نسخه اول به‌صورت **۵ محور + گریپر MG995** ساخته می‌شود.
2. موتورهای هدف فعلاً **NEMA17 با گشتاور اسمی حدود ۳ kg·cm** هستند؛ جریان دقیق باید قبل از خرید درایور مشخص شود.
3. با نسبت تسمه‌های Moveo، تخصیص اولیه جدید: **J1=۳۸:۱، J2=۳۸:۱ دو موتوره، J3=۳۸:۱، J4=۳۸:۱، J5=۳۸:۱**؛ ۵۰:۱ فعلاً گزینه تقویتی است.
4. برای J2 دو موتور NEMA17 با دو درایور جدا داریم؛ قاب برای تعویض به ۵۰:۱ آماده می‌شود، ولی دو موتور را به یک درایور وصل نمی‌کنیم.
5. بعد از تست مکانیک و کالیبراسیون، محور ششم به‌صورت **۶ محور واقعی + گریپر** قابل اضافه شدن است.
6. درایو حرکت با Mega/RAMPS و پروتکل سریال انجام می‌شود؛ محاسبه FK/IK ابتدا روی کامپیوتر باشد و پس از تثبیت ابعاد به firmware منتقل شود.

## نکته سخت‌افزاری مهم

RAMPS 1.4 پنج خروجی درایور استپر دارد: X، Y، Z، E0 و E1. نسخه پنج‌محوره با پنج موتور از این ظرفیت استفاده می‌کند. اگر برای J2 موتور دوم بگذاریم، شش موتور فیزیکی و شش درایور جدا لازم می‌شود؛ دو موتور را به یک A4988 وصل نمی‌کنیم. برای محور ششم آینده نیز درایور خارجی و پایه‌های GPIO رزرو لازم است. MG995 باید از منبع ۵ تا ۶ ولت جداگانه تغذیه شود و نباید مستقیماً از ریل ۵ ولت Mega/RAMPS تغذیه شود.

## روند ادامه کار

پس از مشخص شدن تعداد دقیق موتورها، مدل NEMA، ابعاد گیربکس، برد چاپگر، برد هدف و وزن/برد مورد نظر، ابتدا پیکربندی محور‌ها و تست یک محور را می‌سازیم؛ سپس firmware، ابزار کامپیوتری، مدل سینماتیک و فایل‌های CAD را مرحله‌به‌مرحله اضافه می‌کنیم.
