# بازوی رباتیک استپر / Robotic Arm Stepper

این مخزن برای طراحی و ساخت یک بازوی رباتیک چاپ سه‌بعدی ۵ یا ۶ محوره است؛ با موتورهای استپر، گیربکس‌های سیاره‌ای چاپی ۳۸:۱ و ۵۰:۱، سروو MG995 برای گریپر و کنترلر Arduino Mega 2560 + RAMPS 1.4.

> وضعیت فعلی: **فاز صفر؛ تعیین نیازمندی و معماری نرم‌افزار**. هنوز هیچ قطعه‌ای برای ابعاد یا موتور مشخص، قطعی فرض نشده است.

## سند شروع

- [برنامه پروژه و معماری نرم‌افزار](docs/PROGRAM_PLAN.fa.md)

## تصمیم فعلی پروژه

1. نسخه اول به‌صورت **۵ محور + گریپر MG995** ساخته می‌شود.
2. موتورهای هدف فعلاً **NEMA17** هستند؛ مدل و جریان دقیق باید قبل از خرید نهایی شود.
3. بعد از تست مکانیک و کالیبراسیون، محور ششم به‌صورت **۶ محور واقعی + گریپر** قابل اضافه شدن است.
4. درایو حرکت با Mega/RAMPS و پروتکل سریال انجام می‌شود؛ محاسبه FK/IK ابتدا روی کامپیوتر باشد و پس از تثبیت ابعاد به firmware منتقل شود.

## نکته سخت‌افزاری مهم

RAMPS 1.4 پنج خروجی درایور استپر دارد: X، Y، Z، E0 و E1. بنابراین برای ۶ استپر، محور ششم باید درایور خارجی و سه پایه GPIO رزرو‌شده داشته باشد؛ یا از ابتدا نسخه ۵ محوره ساخته شود. MG995 باید از منبع ۵ تا ۶ ولت جداگانه تغذیه شود و نباید مستقیماً از ریل ۵ ولت Mega/RAMPS تغذیه شود.

## روند ادامه کار

پس از مشخص شدن تعداد دقیق موتورها، مدل NEMA، ابعاد گیربکس، برد چاپگر، برد هدف و وزن/برد مورد نظر، ابتدا پیکربندی محور‌ها و تست یک محور را می‌سازیم؛ سپس firmware، ابزار کامپیوتری، مدل سینماتیک و فایل‌های CAD را مرحله‌به‌مرحله اضافه می‌کنیم.
